# روتينك | متجر العناية بالبشرة

متجر عربي متجاوب لمنتجات العناية بالبشرة، موجّه للسوق السعودي وتُعرض الأسعار بالريال السعودي.

## معاينة الموقع

https://routine-skincare-egypt.mera2225.chatgpt.site

## النشر على Hostinger

المجلد `dist/` هو مجلد مخرجات الموقع. توجد نسخة مطابقة عند جذر المستودع حتى يعمل النشر المضبوط على `public_html`.

## حالة الربط

- المنتجات والأسعار الحالية نموذجية للمراجعة، وتحتاج إلى الاستبدال بكتالوج المتجر الفعلي.
- زر Apple Pay يوضّح أن الربط مطلوب؛ لا تُجمع مدفوعات بعد. يلزم ربط بوابة دفع تدعم Apple Pay واختبارها قبل استقبال الطلبات.
- أحداث المتجر تُرسل إلى `dataLayer` فقط بعد موافقة الزائر. يلزم ربط أداة التحليلات التي تختارها.

الواجهة مبنية بملفات HTML وCSS وJavaScript ثابتة.
