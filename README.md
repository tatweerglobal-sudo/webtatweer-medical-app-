# صيدليات أوبلس | متجر العناية بالبشرة

متجر عربي متجاوب بهوية صيدليات أوبلس، موجه للسوق السعودي والأسعار بالريال السعودي.

## معاينة Hostinger

https://mediumspringgreen-dove-354848.hostingersite.com

## النشر

الملفات `index.html` و`plus-pharmacies-logo.png` و`hero-sunscreen.jpg` و`favicon.svg` موجودة عند جذر المستودع ليتعرف عليها مسار Hostinger `public_html`. كما توجد نسخة الموقع في `dist/`.

## قبل استقبال الطلبات

- المنتجات والأسعار الحالية نماذج للمراجعة ويجب استبدالها بكتالوج الصيدلية الفعلي.
- زر Apple Pay يوضح أن ربط بوابة دفع مطلوبة؛ لا تُجمع مدفوعات حتى تفعيلها واختبارها.
- أحداث المتجر تذهب إلى `dataLayer` بعد موافقة الزائر؛ يلزم توصيل منصة التحليلات التي تختارها.
