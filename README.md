# صيدليات أوبلس | متجر العناية بالبشرة

صفحة منتج عربية متجاوبة لواقي الشمس La Roche-Posay Anthelios UVMune 400 SPF50+، بهوية صيدليات أوبلس وأسعار بالريال السعودي.

## معاينة Hostinger

https://mediumspringgreen-dove-354848.hostingersite.com

## النشر

توجد الملفات المنشورة عند جذر المستودع لمسار Hostinger `public_html`، مع نسخة البناء داخل `dist/`.

## إعدادات العرض والتشغيل

- السعر المرجعي المعروض: 155 ر.س، وسعر عرض الإطلاق: 79 ر.س حتى 30 سبتمبر 2026؛ يجب مراجعة هامش الصيدلية وتأكيد السعر والتوفر قبل اعتماد العرض تجاريًا.
- عداد العرض مرتبط بموعد انتهاء ثابت ولا يعيد تشغيل نفسه للزائر.
- رسالة توصيل المنزل مشروطة بتغطية المدينة والرسوم ومدة التوصيل.
- السلة واجهة تجريبية. Apple Pay وإتمام الدفع يحتاجان إلى ربط بوابة دفع واختبارها قبل استقبال الطلبات.
- أحداث المتجر تصل إلى `dataLayer` بعد موافقة الزائر؛ يلزم توصيل منصة التحليلات المختارة.
